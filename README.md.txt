**Final Year Project Approval & Management System**

📝 **Project Overview**
Developed under the DGP (Digitalization of University Management), this is a comprehensive web-based platform. Its purpose is to manage students’ Final Year Project (FYP) proposals and to digitalize and simplify the supervisor feedback process.

🚀 **Features**

* **Student Portal:** Submit proposals and track their status in real time.
* **Supervisor Dashboard:** Review, accept, or reject proposals and provide feedback.
* **Management Module:** Track all projects and maintain records.
* **Notifications:** Alert system for status updates.

🛠️ **Tech Stack**

* **Frontend:** HTML5, CSS3, JavaScript (Bootstrap for responsive design)
* **Backend:** PHP (Procedural / OOP)
* **Database:** MySQL
* **Server:** XAMPP / WAMP

📂 **Installation Guide**

1. Clone or download this repository.
2. Place the project folder in your local server’s `htdocs` directory.

3. Database Setup:**

* Open phpMyAdmin.
* Create a new database (e.g., `fyp_management`).
* Import the `.sql` file available in the `database/` folder.
4. Update your database credentials (host, user, password) in the `config.php` file.

5. Open your browser and go to `localhost/project_folder_name`.
